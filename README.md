# 🎯 Real-Time Object Detection & Tracking using YOLOv8 & OpenCV

This project implements real-time multi-object detection and persistent tracking on live video feeds or webcam streams. Developed as part of the **CodeAlpha Artificial Intelligence Internship**.

---

## 🚀 Features
- **Real-Time Detection:** Powered by Ultralytics **YOLOv8** pre-trained models.
- **Persistent Object Tracking:** Uses **ByteTrack** to maintain consistent object track IDs across frames (`persist=True`).
- **Live FPS Counter:** Real-time performance monitoring rendered directly onto the video feed.
- **Flexible Inputs:** Seamlessly accepts webcam inputs (`--source 0`) or video files.
- **Video Export:** Option to record and save annotated detection clips to disk.
